gl_extractor — Privacy Policy

Last updated: July 12, 2026

gl_extractor is an app for Shopify merchants that (1) reads a store's published theme code so it can be reviewed and patched by an AI assistant, and (2) runs store analytics queries via Shopify's ShopifyQL API to surface performance metrics inside the app.

What we collect

  • Store identifier (your myshopify.com domain).
  • OAuth access and refresh tokens issued by Shopify when you install the app, used only to call the Shopify Admin API on your store's behalf.
  • Theme code (Liquid templates, sections, snippets) for the specific pages you ask the app to analyze.
  • Aggregate store analytics (e.g. sessions, sales, conversion rate) returned by ShopifyQL. We do not request or store individual customer records, names, emails, or order-level personal data.

How we use it

Theme code and aggregate analytics are used solely to generate review feedback and code suggestions for the merchant who installed the app. Extracted code and metrics may be passed to our internal AI analysis service to generate those suggestions; they are not sold, shared with advertisers, or used for any purpose beyond that.

Storage and security

Access and refresh tokens are encrypted at rest using AES-256-GCM before being stored in our database. Data is transmitted exclusively over HTTPS. Tokens and store data are deleted immediately when a merchant uninstalls the app, per Shopify's mandatory app/uninstalled and shop/redact webhooks.

Data loss prevention

We limit what could ever be lost or exposed by minimizing what we store in the first place: only a store's domain and encrypted OAuth tokens, never customer PII. Tokens are encrypted at rest (AES-256-GCM) so a raw copy of the database is not usable on its own. Data is held on a managed, persistent volume rather than ephemeral storage, and production access is restricted to the app's single developer through Railway and Shopify Partner account authentication. Because no unrecoverable customer data is stored, the practical failure mode of losing our database is a merchant reinstalling the app to reissue tokens — not loss of customer information.

Security incident response

If a security incident is discovered (e.g. suspected unauthorized access to our database or hosting account), we will: (1) rotate the affected credentials — API secrets, encryption keys, and hosting account passwords — immediately; (2) revoke and force re-authentication of OAuth tokens for affected stores; (3) notify affected merchants at the contact email on file within a reasonable timeframe once the scope of the incident is understood; and (4) document the incident and the fix applied to prevent recurrence. Given we do not store customer PII, the primary asset to protect in any incident is store OAuth tokens, which can be invalidated and reissued without impact to merchants' underlying data.

Retention

We retain store data only for as long as the app remains installed on that store. Uninstalling the app triggers deletion of all stored tokens and associated data.

Your rights

Merchants can request deletion of their data at any time by uninstalling the app, or by contacting us directly using the details below. We honor Shopify's mandatory GDPR compliance webhooks (customers/data_request, customers/redact, shop/redact).
